# Brightloop Frontend

A subscription management dashboard built using React and Vite.

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Lucide React
- Recharts

## Features

- Dashboard with revenue statistics.
- Product and plan management.
- Customer management.
- Subscription tracking.
- Quotation and invoice management.
- Discounts and payment tracking.
- Reports and analytics.

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Build

```bash
npm run build
```
